# EcoTech Digital — Présentation Professionnelle & Soutenance Académique

Ce dossier contient la présentation complète, professionnelle et interactive de la startup tunisienne **EcoTech Digital** et de sa plateforme citoyenne **EcoConnect**, développée pour le cours universitaire **« Techniques de recherche d’emploi et Marketing de soi »**.

---

## 📁 Contenu du Projet

1. **`index.html`** : Présentation web interactive responsive (Design haut de gamme Vert Forêt, Menthe & Blanc) avec :
   - Mode Présentation 16:9 immersif avec navigation au clavier et en plein écran (`F`).
   - **Mode Édition en direct** (`E`) permettant de modifier n'importe quel texte directement dans le navigateur et de le sauvegarder.
   - **Tiroir des Notes de l'Orateur** (`N`) contenant le script d'oral mot à mot et les conseils pour le professeur.
   - **Vue en Grille** (`O`) pour naviguer instantanément entre les 12 diapositives.
   - **Minuteur de soutenance intégré** pour s'entraîner à respecter le temps imparti.
   - **Export PDF / Impression** optimisé en format 16:9 paysage.
   - Maquettes réalistes intégrées : Mockup mobile EcoConnect interactif, feed Instagram avec grille de 6 publications, diagrammes de synergie et calendrier éditorial.

2. **`EcoTech_Digital_Presentation.pptx`** : Présentation PowerPoint 16:9 widescreen native et entièrement modifiable :
   - Compatible avec Microsoft PowerPoint, Google Slides, Keynote et LibreOffice.
   - Couleurs, formes, cartes, typographies et encadrés 100 % éditables.
   - Notes du présentateur incluses sous chaque diapositive dans le volet Notes.

3. **`RAPPORT_ET_GUIDE_ORAL.md`** : Guide complet d'accompagnement académique :
   - Script d'oral détaillé pour les 12 diapositives avec durées suggérées.
   - FAQ de soutenance avec questions probables du jury et réponses argumentées.
   - Articulation avec les objectifs du cours de Marketing de soi.

4. **`generate_pptx.js`** : Script Node.js permettant de régénérer le fichier `.pptx` à tout moment.

---

## 🚀 Comment Lancer la Présentation Web

1. Ouvrez simplement le fichier `index.html` dans votre navigateur web préféré (Google Chrome, Microsoft Edge, Mozilla Firefox ou Safari).
2. Aucun serveur ni installation n'est requis : l'application est 100 % autonome et fonctionne également hors ligne.

### ⌨️ Raccourcis Clavier :
- **Flèche Droite (`→`) / Espace / Page Down** : Diapositive suivante
- **Flèche Gauche (`←`) / Backspace / Page Up** : Diapositive précédente
- **Touche `F`** : Activer / Désactiver le mode plein écran
- **Touche `N`** : Ouvrir / Fermer le volet des notes de l'orateur
- **Touche `O`** : Ouvrir la vue en grille (aperçu des 12 slides)
- **Touche `E`** : Activer le mode édition directe de texte
- **Touche `Échap`** : Fermer les fenêtres modales et tiroirs
- **Touche `Home`** : Revenir à la première diapositive
- **Touche `Fin`** : Aller à la dernière diapositive

## 🎓 Personnalisation des Détails Académiques

Pour personnaliser la diapositive de couverture avec votre nom, votre filière et votre établissement :
- Dans la **présentation web (`index.html`)** : vous pouvez directement taper vos informations dans les champs de la première diapositive (la sauvegarde locale est automatique) ou activer le **Mode Édition (`E`)**.
- Dans le fichier **PowerPoint (`EcoTech_Digital_Presentation.pptx`)** : ouvrez le fichier dans PowerPoint et éditez directement le bloc de texte de la diapositive 1.
